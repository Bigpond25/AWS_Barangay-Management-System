# React + TypeScript + Vite

This template provides a minimal setup to get React working in Vite with HMR and ESLint rules.

## Code Quality

This project uses ESLint, TypeScript, and Prettier for code quality:

```bash
# Run all checks
npm run analyse

# Type checking
npm run type-check

# Linting
npm run lint
npm run lint:fix

# Formatting
npm run format
npm run format:check
```

See [../LINTING_SETUP.md](../LINTING_SETUP.md) for complete documentation.

## Development

```bash
# Install dependencies
npm install

# Start dev server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## ESLint Configuration

The project uses type-aware ESLint rules with TypeScript. Configuration is in `eslint.config.js`.
